# Social Post

**Niche: AI Tools for Small Businesses**

Turn each day's brief into social posts that drive newsletter subscribers and client leads. Learn and optimize from past performance.

## Performance-First Approach

Before writing, check `./performance/social-log.md` to see which angles, formats, and hooks have driven the most:
- Profile views / impressions
- Newsletter signups attributed to social
- Comments and shares

Use what works. Drop what doesn't.

## Proven Formats for This Niche

Ranked by typical engagement for SMB AI content:

**#1 — The Use Case (highest engagement)**
```
A [type of small business] owner saved [X hours/$/headaches] using [AI tool].

Here's exactly how they did it:

[3-5 specific steps]

Tool used: [Name] — [price/free]

[Newsletter CTA]
```

**#2 — The Comparison**
```
[Tool A] vs [Tool B] for small businesses:

[Tool A]:
✓ [strength]
✗ [weakness]
Price: $X/mo

[Tool B]:
✓ [strength]
✗ [weakness]
Price: $X/mo

Winner for [specific use case]: [Tool]

[Newsletter CTA]
```

**#3 — The Quick Win**
```
You can [achieve outcome] in [time] using [AI tool].

Here's the exact prompt/workflow:

[Specific, copy-pasteable instructions]

Free to try: [URL]

[Newsletter CTA]
```

**#4 — The Warning**
```
If you're using [Tool], you need to know this:

[What changed — price, feature removed, shutdown, security issue]

The best alternative right now: [Tool] — [why]

[Newsletter CTA]
```

**#5 — The Number**
```
[Specific stat or finding] — and here's what it means for your business:

[2-3 implications for SMBs]

[Newsletter CTA]
```

## Newsletter CTA (rotate these, track which converts best)

- "I cover this every day. Free newsletter → [link]"
- "Get the full breakdown in today's issue → [link]"
- "More like this: [link] (free, daily)"
- "I find these every day. Subscribe → [link]"

## LinkedIn vs X

**LinkedIn:** Use format #1 or #2. More text is fine. Professional tone but not corporate. End with a question to drive comments.

**X/Twitter:** Lead with the hook only. Under 280 chars. Link to newsletter. If the finding has depth, thread it (3-5 tweets max).
