# Prospect Research

Find 50 qualified real estate agent prospects ready for cold outreach.

## Target profile

The ideal prospect is:
- A solo agent or small team (2–5 agents)
- Active — has listings in the last 90 days
- Doesn't appear to have a virtual assistant or receptionist already
- Based in a metro area (more call volume = higher value to them)
- Luxury agents, new construction agents, and buyer's agents are highest value

## Sources to search

1. **Realtor.com agent directory** — search by city, filter by active listings
2. **Zillow agent finder** — similar, good for finding contact info
3. **LinkedIn** — search "real estate agent [city]", look for profiles with contact info
4. **State licensing databases** — most states publish licensed agent lists with email/phone (e.g., Texas: TREC lookup, California: DRE lookup)
5. **Facebook real estate groups** — scan member lists for active agents

## What to collect per prospect

For each prospect, record:
- Full name
- Brokerage name
- City / state
- Email (if findable)
- Phone (if findable)
- Website URL (if they have one)
- Estimated activity level (high / medium / low based on listings)
- Notes (anything that personalizes the outreach)

## Output format

Save as a markdown table in `shared-workspace/sales/prospects/[date]-[city].md`:

```
| Name | Brokerage | City | Email | Phone | Website | Activity | Notes |
|------|-----------|------|-------|-------|---------|----------|-------|
```

Aim for 50 prospects per run. Quality over quantity — a prospect with a real email and active listings is worth 10 names with no contact info.
