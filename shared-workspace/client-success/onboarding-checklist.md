# RealtyVoice AI — Client Onboarding Checklist

> **For Client Success Team use + client self-service**
> Complete all items within the first 24 hours to ensure a smooth launch.

---

## Phase 1: Account Setup (Day 0 — 10 minutes)

- [ ] **Account created** — Client has logged into the dashboard
- [ ] **Profile complete** — Name, brokerage name, and license number entered
- [ ] **Service area configured** — Neighborhoods/zip codes added
- [ ] **Business phone number confirmed** — The number clients currently use
- [ ] **Call forwarding enabled** — Business line forwarded to RealtyVoice AI number
  - *Verify: Place a test call to confirm AI answers*

---

## Phase 2: AI Receptionist Configuration (Day 1 — 15 minutes)

- [ ] **AI persona named** — Receptionist has a name (e.g., "Jordan")
- [ ] **Greeting script set** — "Thank you for calling [Agent Name] with [Brokerage]..."
- [ ] **Tone selected** — Warm & friendly / Professional & direct / Luxury concierge
- [ ] **Value propositions added** — 2–3 bullet points about the agent's unique selling points
- [ ] **Lead qualification questions configured:**
  - [ ] Buying, selling, or both?
  - [ ] Timeline (immediate / 1–3 months / 6+ months)?
  - [ ] Pre-approved for financing?
  - [ ] Currently working with another agent?
  - [ ] Price range or neighborhood preference?
- [ ] **Call-to-action set** — "I'll have [Agent Name] call you back within [timeframe]"

---

## Phase 3: Integrations (Day 1–3)

- [ ] **CRM connected** (select one):
  - [ ] Follow Up Boss
  - [ ] KvCORE
  - [ ] HubSpot
  - [ ] GHL / GoHighLevel
  - [ ] Other: ___________
  - [ ] No CRM (leads emailed to agent)
- [ ] **SMS follow-up enabled** — Auto-text sent to callers after every call
- [ ] **Email notifications configured** — Daily lead summary delivered to agent's inbox
- [ ] **Calendar sync** (Pro/Team only) — Google Calendar or iCal connected for showing bookings

---

## Phase 4: Testing & Verification (Day 1–3)

- [ ] **Test call completed** — CS rep or agent places test call
- [ ] **AI answered correctly** — Greeting matches configured script
- [ ] **Lead captured** — Test lead appears in dashboard and CRM
- [ ] **SMS received** — Follow-up text delivered after test call
- [ ] **Email notification received** — Lead summary email delivered

---

## Phase 5: Training & Handoff (Day 3–7)

- [ ] **Dashboard walkthrough completed** — Agent knows how to:
  - View call logs and recordings
  - See lead capture data
  - Export or share lead reports
- [ ] **Mobile access confirmed** — Agent can view dashboard on phone
- [ ] **After-hours routing configured** — Urgent calls vs. AI-handled calls defined
- [ ] **"Success metrics" baseline set** — Documented pre-RealtyVoice missed call rate
- [ ] **Week 1 check-in scheduled** — 15-minute call booked with CS rep

---

## Phase 6: Success Confirmation (Day 7)

- [ ] **First 7-day report reviewed** — Calls handled, leads captured, response rate
- [ ] **Agent satisfied** — Confirmed setup is working as expected
- [ ] **Any issues resolved** — Open tickets closed or escalated
- [ ] **Upsell opportunity noted** — Flag for Pro/Team upgrade if volume warrants it
